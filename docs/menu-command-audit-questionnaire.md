# Опросник по аудиту меню AKB5

Основание: `docs/menu-command-audit.md`
Цель: собрать от команды и главного разработчика чёткие решения по перегруженным, спорным и опасным пунктам меню.

## Как заполнять

- По каждому вопросу выбрать один вариант, если не указано `можно выбрать несколько`.
- Вариант с пометкой `[рекомендуется]` отражает рекомендацию из аудита.
- Если выбран другой вариант, желательно кратко указать причину.
- После заполнения документ можно использовать как прямое техническое задание на переработку меню.

Формат ответа:

```text
Вопрос 1: B
Комментарий: ...
```
